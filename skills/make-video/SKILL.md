# Make a video

The whole video is generated by the engine in this plugin. Your job is to write a good script, then build and deliver it.

## 1. Locate the engine
```bash
ROOT="${CLAUDE_PLUGIN_ROOT:-$(git rev-parse --show-toplevel)}"; ls "$ROOT/engine/render.js"
```
If `CLAUDE_PLUGIN_ROOT` is empty and you are not inside the `2d-video-maker` repo, clone `https://github.com/fahadisthegoat2-hub/2d-video-maker` to a scratch folder and use that as `ROOT`.

## 2. Write the script
- Read the `video-script` skill for the exact format: scene types, character options and shots.
- Read the `story-and-pacing` skill for how to make it hook viewers.
- Save the script as `scripts/<slug>.txt` (in the user's project if they have one, otherwise in your scratchpad).

Default to 8–14 scenes for a 1–2 minute video. Open with the strongest image, and never with a title card.

## 3. Check frames before delivering
```bash
node "$ROOT/engine/render.js" scripts/<slug>.txt out/<slug>.mp4 --novoice --still 1,6,12,20
```
Look at the JPGs it writes (`out/<slug>-<t>.jpg`). Fix any overlaps, for example characters standing in the campfire or labels covering faces, by changing `x=` positions or `shots:`. Do one pass of fixes only.

## 4. Deliver
Always build the on-device player. It is what the user opens on iPad or phone.
```bash
node "$ROOT/engine/build-player.js" scripts/<slug>.txt out/<slug>-player.html
```
Publish `out/<slug>-player.html` with the Artifact tool:
- `capabilities: {"tts": {}, "downloads": true}`
- `icon: "film"`
- a one-sentence `description`

Give the user the link. In it they can press Play, edit the script, and use **Export video** then **Save video** to record a file on their own device.

If the user wants an MP4 and Chromium and ffmpeg exist (they do in Claude Code cloud sessions), also run the full render. It uses the edge-tts voice when there is internet:
```bash
(cd "$ROOT" && [ -d node_modules ] || npm install --prefix "$ROOT" --silent)
node "$ROOT/engine/render.js" scripts/<slug>.txt out/<slug>.mp4
```
Then send the MP4 to the user.

## Rules
- Use original characters only. Never recreate a copyrighted character, logo or show; describe them with original designs instead.
- Keep replies short. The video is the deliverable.
